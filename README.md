# SQL RAG Agent 🔍

> Natural language → SQL → results, powered by a **local LLM** — no API key needed.

A portfolio project demonstrating a Retrieval-Augmented Generation (RAG) pipeline for SQL generation, built entirely with open-source tools that run on your machine.

---

## What it does

You type a plain English question. The agent:

1. **Retrieves** the relevant table schemas from a vector store (cosine similarity)
2. **Augments** a prompt with that schema context
3. **Generates** a SQL query using a local LLM (Ollama)
4. **Executes** the query on a real SQLite database
5. **Visualises** the results with matplotlib

```
"Which region has the highest revenue?"
           │
           ▼
   Embed question → find relevant tables
           │
           ▼
   [schema context] + question → LLM
           │
           ▼
   SELECT region, SUM(total_amount) ...
           │
           ▼
   Chart + DataFrame
```

## Getting started

### 1. Install Ollama

Download from [ollama.com](https://ollama.com) and pull the two required models:

```bash
ollama pull llama3.2
ollama pull nomic-embed-text
```

### 2. Clone and install Python deps

```bash
git clone https://github.com/YOUR_USERNAME/sql-rag-agent
cd sql-rag-agent
pip install -r requirements.txt
```

### 3. Seed the database

```bash
python src/seed_db.py
```

### 4. Open the notebook

```bash
jupyter notebook notebooks/sql_rag_agent.ipynb
```

Run all cells from top to bottom.

## Core concepts demonstrated

- **Vector embeddings** — converting schema text into semantic vectors
- **Cosine similarity search** — finding the most relevant tables for each question
- **Prompt engineering** — structured prompts that constrain LLM output to valid SQL
- **RAG evaluation** — comparing RAG vs full-schema baseline on SQL success rate
- **Local LLMs** — running everything offline with Ollama
